# Протокол конституции

`AGENT.md` в корне workspace — project-wide правила и конвенции, обязательные для любой задачи. Конституция читается каждой ролью на каждой итерации и применяется к коду, тестам и документации.

## Что задаёт

Конституция задаёт общие правила и конвенции проекта. Конкретный набор секций определяет разработчик — состав компонентов у каждого проекта свой.

## Как применяется

Файл, содержащий заголовок `# Comments` или цитату из конституции, — дефект. Разработчик пишет правила один раз; модель их применяет при каждой записи файла.

## Протокол составления

1. **Прочитать стек.** Записать каждую библиотеку, драйвер, фреймворк и его зафиксированную версию.
2. **Прочитать целевые файлы.** Секция появляется только тогда, когда называет правило, охватывающее больше одного файла.
3. **Одна секция на каждый concern.** Заголовки секций совпадают с concerns проекта.
4. **Одно правило — одно предложение.** Императив. Каждое правило проверяемо чтением одного файла.
5. **Называть инвариант, не код.** Правило формулирует предотвращаемый сбой, удовлетворяемый контракт или источник истины.
6. **Универсального шаблона нет.** Набор секций выбирает разработчик. В проекте без HTTP секции `# HTTP` нет. В проекте без Pydantic секции `# Pydantic` нет.
7. **Без дублирования правил между секциями.** Если одно правило попадает под `# Database` и под `# SQL` — оно живёт в одной секции, чей concern оно описывает.
8. **Без примеров кода в конституции.** Каждое правило — проза. Конституция формирует файлы; в них она не появляется.
9. **Без секции `# Rules`.** Каждое правило живёт под своей concern-секцией.
10. **Проверить перед возвратом.** Каждое правило императивное, проверяемое и живёт ровно под одной concern-секцией.

## Финальная проверка

- [ ] Секции совпадают с concerns проекта; универсального шаблона нет
- [ ] Каждое правило — одно предложение, императив
- [ ] Каждое правило проверяемо чтением одного файла
- [ ] Ни одно правило не цитирует код
- [ ] Ни одно правило не повторяет другое
- [ ] Секции `# Rules` нет
- [ ] `# Comments` описывает правило, а не образец
- [ ] `# Constitution applies silently` — последняя секция
- [ ] Весь файл помещается в одно контекстное окно вместе со спекой задачи
